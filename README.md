# NeuralContaMX — actualizaciones

Este repositorio solo publica los archivos de cada versión de NeuralContaMX
(programa, instalador y el manifiesto firmado `actualizacion.json`).
El programa revisa aquí si hay una versión nueva.

## Descargas

- **[Descargar el instalador de NeuralContaMX](https://github.com/NCMX-Conta/actualizaciones/raw/main/Instalar-NeuralContaMX.exe)** (siempre la última versión)

- Instalador de la versión actual: carpeta `v1.6.3` → `Instalar-NeuralContaMX-1.6.3.exe`
