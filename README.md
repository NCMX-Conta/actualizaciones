# NeuralContaMX — actualizaciones

Este repositorio solo contiene el manifiesto firmado `actualizacion.json`,
que NeuralContaMX consulta para saber si hay una versión nueva.
Los archivos de cada versión (programa e instalador) se publican en
[Releases](https://github.com/NCMX-Conta/actualizaciones/releases).

## Descargas

- **[Descargar el instalador de NeuralContaMX](https://github.com/NCMX-Conta/actualizaciones/releases/latest/download/Instalar-NeuralContaMX.exe)** (siempre la última versión)
